# Triage（分拣）

输入：提示词里给出的事件文件路径，例如 `inbox/20260903-1015-mail-42.md`。

步骤：
1. 读事件文件的 frontmatter 和正文。
2. 读 `_topics.md` 的主题表和路由规则。
3. 判断最匹配的 slug，给出 0 到 1 的置信度和一句话理由。多个命中时选最高的，其余写进 `also`。
4. 按路由规则处理置信度不足的情况（路由到 `_unsorted`）。
5. 不要修改任何文件，不要移动事件文件。路由日志由脚本写入，分拣之外的处理由后续步骤完成。

输出：回答的最后一行必须是且只能是下面这种格式，方便脚本解析：

ROUTE_JSON: {"topic": "<slug>", "confidence": 0.0, "reason": "<一句话>", "also": []}
